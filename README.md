# 🦾 Кибер-Комбайн — Telegram бот для кибербезопасности

Многофункциональный бот для OSINT, анализа безопасности и мониторинга.

## 🔥 Возможности

### 🔍 OSINT
- `/domain` — WHOIS, DNS, IP домена
- `/ip` — геолокация, провайдер, координаты
- `/email` — проверка email в утечках (HIBP)

### 🛡️ Безопасность
- `/check` — проверка ссылки, SSL сертификат
- `/hash` — MD5/SHA256 файла
- `/ssl` — информация о SSL сертификате

### 📊 Анализ
- `/scan` — сканирование портов (TOP 20)
- `/log` — анализ логов на аномалии
- `/decode` — декодирование Base64/URL/Hex

### 🔑 Инструменты
- `/passgen` — генератор безопасных паролей
- `/exif` — метаданные фото (GPS, дата, камера)

### 📱 Мониторинг
- `/monitor add` — добавить хост
- `/monitor list` — список хостов
- `/monitor status` — проверить доступность

### 📋 Отчеты
- `/report` — сгенерировать отчет по всем проверкам
